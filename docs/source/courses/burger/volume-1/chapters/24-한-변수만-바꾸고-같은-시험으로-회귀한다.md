# 24. 한 변수만 바꾸고 같은 시험으로 회귀한다

수정 전 증거를 보존하고 한 변수만 바꾼 뒤 같은 조건으로 다시 시험해 승격·rollback·인수인계를 닫는다.

![증상 고정, 수정 전 증거, 한 변수 변경, 정적·build, 동일 runtime, 회귀 판정, 승격·rollback·인수인계를 연결한 변경 제어 루프.](/_static/generated/diagrams/burger/volume-1/figure-25.png)

LOOP-24-01 · 증상 고정부터 수정·정적검사·동일 runtime·회귀·rollback까지 이어지는 변경 제어 폐루프.

| 단계 | 필수 기록 | 금지 |
| --- | --- | --- |
| 수정 전 | 환경·명령·첫 FAIL·hash | 기억에 의존 |
| 한 변수 변경 | diff·가설·예상 영향 | 동시 다중 변경 |
| 정적·build | lint·test·colcon 결과 | runtime PASS 과장 |
| 동일 runtime | 같은 경로·속도·조건 | 성공 사례만 선택 |
| 결론 | 승격 또는 rollback·재개점 | 실패 덮어쓰기 |

```bash
git diff --check
colcon test --packages-select burger_nav2_goal_client
colcon test-result --verbose
sha256sum before/* after/*
```

주의  Ruff·pytest·colcon test가 통과해도 simulator·DDS·실물 통합은 별도 HOLD다. 실패 evidence를 지우지 않고 rollback 절차와 재개점을 남긴다.
