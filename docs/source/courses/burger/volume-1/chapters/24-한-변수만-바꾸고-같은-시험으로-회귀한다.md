# 24. 한 변수만 바꾸고 같은 시험으로 회귀한다

수정 전 증거를 보존하고 한 변수만 바꾼 뒤 같은 조건으로 정적·runtime 회귀와 rollback을 닫는다.

## 학습 목표

- 수정 전 환경·명령·첫 FAIL·hash를 보존한다.
- 한 변수 diff와 가설·예상 영향을 기록한다.
- 정적 PASS와 simulator·DDS·실물 runtime PASS를 분리한다.

## 선수 조건

- Lesson 22의 첫 FAIL
- Lesson 23의 RUN_ID Evidence Pack

## 핵심 개념

| 단계 | 필수 기록 | 금지 |
| --- | --- | --- |
| 수정 전 | 환경·명령·첫 FAIL·hash | 기억에 의존 |
| 한 변수 변경 | diff·가설·예상 영향 | 동시 다중 변경 |
| 정적·build | lint·test·colcon 결과 | runtime PASS 과장 |
| 동일 runtime | 같은 경로·속도·조건 | 성공 사례만 선택 |
| 결론 | 승격 또는 rollback·재개점 | 실패 덮어쓰기 |

## 준비

- 현재 장비·shell·경로·ROS 배포판을 확인한다.
- 이 Lesson에서 필요한 실제 입력이 없으면 결과를 만들지 않고 `HOLD`로 남긴다.
- 명령과 관찰을 같은 실행 회차의 증거로 연결할 저장 위치를 준비한다.

## 실행

```bash
git diff --check
colcon test --packages-select burger_nav2_goal_client
colcon test-result --verbose
sha256sum before/* after/*
```

## 예상 결과

:::{admonition} 예상 결과의 경계
:class: expected-result
아래 항목은 원문이 제시한 판정 기준이다. 실제 장비·설치본의 출력 로그를 이 문서가 대신 만들지는 않는다.
:::

- 수정 전후 diff와 hash를 비교한다.
- 정적·build test 뒤 같은 runtime 조건으로 회귀한다.
- 승격 또는 rollback과 재개점을 결정한다.

## 관찰 포인트

- Ruff·pytest·colcon test 통과가 simulator·DDS·실물 통합을 자동 PASS하지 않는다.
- 실패 evidence를 지우지 않는다.

## PASS / HOLD / FAIL

::::{grid} 1 1 3 3
:gutter: 2
:class-container: status-gate-grid

:::{grid-item-card} ✓ PASS
:class-item: status-pass
한 변수 변경의 가설이 동일 시험으로 검증되고 승격·rollback·재개점이 남는다.
:::

:::{grid-item-card} ◇ HOLD
:class-item: status-hold
동일 runtime을 실행하지 않았거나 정적 PASS만 있다.
:::

:::{grid-item-card} ✕ FAIL
:class-item: status-fail
여러 변수를 동시에 바꾸거나 실패 evidence를 삭제하고 성공 사례만 남긴다.
:::

정상 결과와 STOP 조건을 구분하지 못하면 다음 단계로 진행하지 않는다.

## 실패·문제해결

- 수정 전 기준선 없이 바로 코드 변경
- 다른 지도·속도·경로로 회귀시험
- 정적 test 성공을 실물 통합 성공으로 보고

첫 수정 전에 **마지막 PASS와 첫 FAIL**을 기록하고 한 번에 한 변수만 바꾼다.

## 증거 체크리스트

- [ ] before/after RUN_ID와 hash
- [ ] 단일 diff·가설·예상 영향
- [ ] 정적·build·동일 runtime 결과와 rollback 지점

## 확인 문제

**질문:** pytest와 colcon test가 통과하면 실물 Burger 통합도 PASS인가?

:::{dropdown} 정답 확인
:class-container: knowledge-answer
아니다. simulator·DDS·실물 통합은 별도 runtime 검증층이며 미실행이면 HOLD다.
:::

## 실습 과제

현재 수정 하나를 골라 before evidence, 단일 diff, 같은 회귀시험, 승격 또는 rollback 네 칸을 채운다.
