# 25. 조별 프로젝트는 재현·안전·증거로 완료한다

저장 지도에서 A·B·C 목표를 순찰하고 Cancel·STOP을 확인한 뒤 세 역할이 같은 조건의 세 번 성공을 증명한다.

![저장 지도에서 A·B·C Goal을 순찰하고 Cancel·STOP을 확인한 뒤, 세 역할이 세 번 같은 결과와 Evidence Pack을 남기는 입문 프로젝트.](/_static/generated/diagrams/burger/volume-1/figure-26.png)

PROJECT-25-01 · 지도 기반 3점 순찰, Cancel·STOP, Result·Evidence, 세 역할과 3회 재현을 하나의 완료 계약으로 묶는다.

| 완료 계층 | PASS 기준 | 증거 |
| --- | --- | --- |
| 준비 | map·Localization·Nav2 gate | RViz·TF·상태 log |
| 임무 | A→B→C terminal success | Goal·Feedback·Result |
| 안전 | Cancel 후 command·base 정지 | 담당자·영상·topic |
| 재현 | 같은 조건 3회 | RUN_ID 3개·결과표 |
| 포트폴리오 | 기준선·실패·수정·HOLD | diff·hash·인수인계 |

```bash
# 역할: 안전·운영 / Nav2·코드 / Evidence·QA
# A·B·C Goal은 같은 client를 좌표만 바꿔 순서대로 실행
ros2 action info /navigate_to_pose
ros2 topic info /cmd_vel --verbose
colcon test-result --verbose
```

주의  현재 문서는 프로젝트 완료 계약만 잠근다. simulator 3회·실물 3회·물리 STOP·팀 역할 배정은 실제 증거가 들어오기 전까지 HOLD다.
