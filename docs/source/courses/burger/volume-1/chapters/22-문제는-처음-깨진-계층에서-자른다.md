# 22. 문제는 처음 깨진 계층에서 자른다

안전부터 바퀴까지 위에서 아래로 확인하고, 첫 FAIL과 마지막 PASS를 기록해 무작위 튜닝을 막는다.

![안전, Linux 장치, ROS 환경, graph·QoS, TF·시간, Nav2, OpenCR·바퀴를 위에서부터 확인하고 첫 FAIL과 마지막 PASS를 기록하는 사다리.](/_static/generated/diagrams/burger/volume-1/figure-23.png)

LADDER-22-01 · 안전·장치·환경·graph/QoS·TF/time·Nav2·base를 순서대로 확인하는 첫 실패 사다리.

| 증상 | 마지막으로 증명된 계층 | 다음 확인 |
| --- | --- | --- |
| SSH도 안 됨 | 전원만 확인 | IP·Wi-Fi·SBC |
| topic은 보이나 수신 0 | name·type | endpoint·QoS |
| Path 있음·cmd 없음 | Planner | Controller·local costmap |
| cmd 있음·바퀴 정지 | ROS command | OpenCR·motor·wheel |

```bash
ros2 doctor --report
ros2 topic info /cmd_vel --verbose
ros2 topic hz /cmd_vel
ros2 run tf2_ros tf2_echo map base_link
```

주의  /cmd_vel의 이름·type·publisher가 보이는 것과 실제 바퀴가 움직이는 것은 다른 증거다. 정지 불가·발열·반복 disconnect면 즉시 STOP한다.
