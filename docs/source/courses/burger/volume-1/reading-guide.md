# 이 책을 이렇게 사용한다

본문은 초보자의 첫 성공 경로를 따른다. 실행 순서와 정상 결과를 먼저 확인하고, 문제가 생기면 첫 FAIL 계층까지 되돌아간다.

| 독자 | 먼저 보는 것 | 완료 기준 |
| --- | --- | --- |
| 학생 | 명령 순서·정상 결과·STOP | 따라 하고 결과를 설명한다. |
| 교사 | 시연 순서·실패 주입·평가표 | 수업을 재현하고 판정한다. |
| 회사 신입 | 기준선·트러블슈팅·증거·인수인계 | 첫 실패 계층을 좁힌다. |
| 복습자 | 표·게이트·명령·HOLD 경계 | 필요한 항목을 빠르게 재확인한다. |
