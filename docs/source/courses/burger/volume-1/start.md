# Burger 1권 시작하기

이 1권은 **환경 → 통신 → 좌표 → 실물·simulation → SLAM·Nav2 → 진단·증거·프로젝트** 순서로 진행한다.

## 시작 전 3가지

1. [읽는 법](reading-guide.md)에서 `VERIFY`, `STOP`, `HOLD`의 뜻을 확인한다.
2. [6단계 학습 지도](learning-map.md)에서 현재 단계와 다음 입력을 확인한다.
3. 실제 출력이나 물리 결과가 없으면 문서가 결과를 대신 만들지 않으며 `HOLD`로 남긴다.
