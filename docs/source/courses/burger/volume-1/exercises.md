# 연습 문제

## 개념 확인

1. Package, Executable, Process, Node가 각각 무엇인지 확인 명령과 함께 설명한다.
2. Topic 이름이 보이지만 메시지가 오지 않을 때 type·endpoint·QoS 순서로 조사한다.
3. `position.z`, Quaternion의 `orientation.z`, camera optical z를 구분한다.
4. Goal Accepted와 Succeeded가 왜 다른지 설명한다.
5. Path 생성, velocity command, 실제 wheel motion을 서로 다른 증거로 기록한다.

## 실습 전 HOLD
